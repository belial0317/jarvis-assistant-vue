# 用户操作手册

> 贾维斯 AI 助手（@jarvis/ai-assistant）v0.2.0
> 本手册面向组件的最终使用者，逐一说明每个功能模块的作用与操作方式。
> 接入与部署说明请参阅《快速开始》与《集成指南》。

---

## 快速上手（30 秒）

1. 宿主页面的导航栏或工具栏中，点击 **✦ AI 助手** 图标按钮，打开助手抽屉。
2. 底部输入框输入问题，按 **Enter** 发送（**Shift+Enter** 换行）。
3. AI 回答流式输出中，可随时点击 **停止生成** 中止；已完成的部分内容会被保留。

---

## 一、会话工作台（核心模块）

与 AI 对话的主界面，所有能力在此汇聚。

### 基本操作

| 操作 | 方式 |
|------|------|
| 发送消息 | 输入后按 Enter，或点击发送按钮 |
| 换行 | Shift+Enter |
| 新建会话 | 左上角「新会话」按钮 |
| 切换历史会话 | 「会话历史」列表，点击条目恢复上下文 |
| 置顶会话 | 会话列表中的置顶开关 |
| 删除会话 | 会话列表中的删除按钮 |
| 停止生成 | 流式输出中点击「停止生成」；**已生成的部分内容会保留在会话中**（含 AI 的推理过程），不会丢失 |
| 复制回答 | 消息底部「复制」按钮 |
| 重新生成 | 消息底部「重新生成」按钮 |

### 高级输入

- **@ 引用上下文**：输入 `@` 唤起引用弹层，可选择页面元素或会话内容作为提问上下文。
- **/ 触发技能**：输入 `/` 唤起技能列表（如 NL2SQL），选择后按技能引导继续。

### 消息中的动态内容

| 元素 | 含义 |
|------|------|
| **参考来源** 角标 | 回答依据的证据清单。`📄 文档名 0.73` 表示知识库命中（0.73 为相似度）；`🗄 数据库名·数据库查询结果` 表示数据来自宿主数据库实查；`🖥 当前页面` 表示来自页面感知。**来源可溯源，结论可核查** |
| **深度搜索·第 N 轮** | 复杂问题会被拆解为多个子查询多轮检索；此提示表示检索进度，完成后折叠为「深度搜索 N 轮」摘要 |
| **思考过程**（折叠区） | 推理模型的思考内容，默认折叠 |
| **工具调用卡片** | AI 调用外部工具（如数据库查询）时的执行状态与耗时，可展开查看参数与结果 |
| **SQL 结果表格** | NL2SQL 查询的可视化结果（SQL 语句已脱敏，不向前端暴露表结构） |

### 模型切换

输入框上方下拉可切换模型（如 GLM-5.3-Flash / DeepSeek）。会话模型持久化保存，切换会话自动恢复。

## 二、Agents 管理

智能体 = 模型 + 提示词 + 权限 + 工具绑定的角色封装。

### 新建 / 编辑 Agent

| 配置项 | 说明 |
|--------|------|
| 名称 / 头像 / 描述 | 角色标识 |
| 系统提示词 | 定义角色、行为与约束（支持变量注入） |
| 模型 | 该 Agent 使用的 LLM（可与会话默认不同） |
| 温度 / Max Tokens / 最大迭代 | 生成参数；最大迭代控制工具调用循环轮数 |
| 知识库绑定 | 勾选后该 Agent 回答时自动检索所选知识库（RAG） |
| 数据源绑定 | 勾选后可查询对应业务数据库；**不选 = 不限定**（可查全部启用中的数据源）；若需禁止某 Agent 查库，绑定后清空即可 |
| MCP 服务器 | 绑定后可调用对应 MCP 工具 |
| 敏感信息过滤 | 内置手机号/邮箱/身份证等正则脱敏规则，可开关 |
| 主题色 | 会话中的 Agent 标识色 |

### 会话中切换 Agent

会话工作台顶部点击当前 Agent 名称，弹出选择器。**切换不清空消息**，仅影响后续回答的角色与知识范围。

### 内置 Agent

- **页面感知分析师**（👁）：系统级解读引擎，负责生成页面画像。可编辑其提示词调整解读维度，可禁用（禁用后页面解读层关闭，对话不受影响）；**不可删除**。
- 内置默认 Agent：未选择 Agent 时的对话兜底。

## 三、知识库

让 AI 回答有据可依：上传文档 → 自动分块向量化 → 会话中自动检索引用。

### 建库与上传

1. 「新建知识库」：填写名称与描述；分块（最大 tokens/重叠）、检索（Top-K/分数阈值）可用默认值。
2. 进入知识库 →「上传文档」（支持 PDF、DOCX、TXT、MD、HTML、JSON、CSV）。
3. 上传后自动完成 解析 → 分块 → 向量化，状态变为 ready 即可使用。

### 文档管理

| 操作 | 作用 |
|------|------|
| 查看分段 | 查看该文档被切分的所有片段 |
| 重新索引 | 用现有分段重建向量索引（文档内容变更后使用） |
| 删除 | 移除文档及其全部向量 |

### 检索测试

知识库详情页内置检索测试框：输入查询文本，即时返回命中片段与相似度，用于验证上传效果。

### 引用与溯源

会话中命中知识库时，回答下方会出现来源文档名与相似度；同一文档被多轮引用时自动去重。

## 四、MCP 管理

接入外部工具协议（Model Context Protocol），扩展 AI 的执行能力。

| 操作 | 说明 |
|------|------|
| 新增服务器 | 填写 transport（streamable-http 等）、URL 与鉴权信息 |
| 健康探测 | 系统定时探测所有服务器连通性，状态与错误展示在列表 |
| 工具发现 | 连接成功后自动拉取该服务器的工具列表 |
| 绑定到 Agent | 在 Agent 表单中勾选，会话中 AI 即可调用（高风险工具有授权审批流程） |

---

## 五、供应商管理

管理 AI 模型的来源，支持多供应商并存与一键切换。

| 配置项 | 说明 |
|--------|------|
| 供应商 | 名称、Base URL、API Key（列表中仅显示掩码，不可回看明文） |
| 模型目录 | 每个供应商下注册模型（名称/上下文长度/是否支持流式/工具/视觉/思考） |
| 默认模型 | `is_default` 标记的模型为新会话的默认选择；同一时刻仅一个默认 |

> 当前已接入：**智谱**（GLM-5.3-Flash，默认）、**SenseNova**（glm-5.2 等）。
> 切换供应商无需改代码：新增供应商 → 注册模型 → 设为默认 → 新会话即生效。

## 六、感知配置

让 AI「看懂」宿主页面：为不同路由配置内容提取规则。

| 配置项 | 说明 |
|--------|------|
| 路由模式 | 精确匹配 / 前缀匹配 / 正则匹配 |
| CSS 选择器 | 指定提取页面哪些区域（默认整页主内容区） |
| 提取策略 | 自动（表格转 Markdown+文本）/ 仅表格 / 仅文本 / 全量（不压缩） |
| 启用开关 | 按路由启停 |

### 页面画像

感知配置页顶部展示**当前页面画像**：页面类型、业务内容、实体清单（如订单号/客户/金额）、数据现状、可执行操作流程、AI 主动洞察与推荐话题。

画像由内置「页面感知分析师」Agent 生成，同页面内容缓存复用（重复打开零开销）。**编辑该 Agent 的提示词即可调整解读维度**。

### 感知优化

目标列表 + 指标汇总：为感知质量设定优化目标，查看评分与验证报告（体验优化闭环入口）。

## 七、Skill 管理

技能 = 预置提示词模板 + 触发关键词。会话中输入 `/` 可看到全部可用技能（如 NL2SQL）。支持新建、编辑、启停。

---

## 八、NL2SQL 审计

自然语言查库的全量审计：每次查询的生成 SQL（已脱敏）、执行结果、耗时与状态。

| 操作 | 说明 |
|------|------|
| 查看详情 | 展开单次查询的完整过程 |
| 用户反馈 | 👍/👎 标记结果质量，反馈进入自学习闭环（驱动后续生成优化） |

> 会话中触发方式：输入 `/` 选择 NL2SQL 技能，或直接用自然语言提问数据类问题（AI 会自动路由到数据库）。

## 九、设置

| 配置项 | 说明 |
|--------|------|
| 后端服务地址 | 组件连接的平台服务端（写入 localStorage，可运行时切换） |
| API Key | 组件访问凭据（管理端可配置为不可见） |
| 模型列表 | 控制台下发的可选模型白名单（优先于供应商目录） |

> 「服务地址」与「API Key」字段的可见性由管理端开关控制（`serviceUrlVisible` / `apiKeyVisible`），锁定后终端用户不可查看或编辑。

## 十、常见问题

**Q：回答下方没有「参考来源」？**
该会话 Agent 未绑定知识库，或检索无命中（重排后无相关片段）。回答仅基于模型自身能力。

**Q：切换了默认模型，旧会话还是用旧模型？**
会话模型持久化保存。在会话下拉中手动切换，或新建会话。

**Q：停止生成后内容会丢吗？**
不会。已生成的部分内容（含推理过程）自动保留在会话中，状态标记为已停止。

**Q：数据类问题的数字可信吗？**
可信。数据类子查询会自动路由到宿主数据库实查（受 SQL 安全校验与行级权限保护），回答中的数字来自真实查询；同时在「NL2SQL 审计」中可追溯每次查询。
